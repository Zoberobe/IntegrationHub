03 / UNDER THE HOOD

Why the retry is safe

Each boundary has a durable record and a stable key.

01

Payment

A stable order key is sent with the Stripe PaymentIntent request. Repeating the request does not start a second payment.

02

Webhook

The raw body signature and timestamp are checked. A unique event ID makes repeated delivery an acknowledged duplicate.

03

Shipping

The job persists in PostgreSQL. Celery retries temporary failures, and a unique shipment key prevents double creation.

The backend and tests are available for inspection.
