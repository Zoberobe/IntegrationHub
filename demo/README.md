# Public demo

This is a static, browser-only simulation of IntegrationHub's order state transitions. Buttons do not call Stripe, the API, Redis, or PostgreSQL. The embedded video and linked JSON files document a separate real Stripe test-mode run. The backend source and reproducible validation steps are in the parent project.

Open `index.html` through a static HTTP server for local preview. The published Site uses the same files from `demo/`.
